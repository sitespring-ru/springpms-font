Подключение через файл стилей

Без Sass и сборки — один <link> на src/style.css. Все иконки — в галерее.

1. Подключить

<link rel="stylesheet"
      href="node_modules/@sitespring/springpms-font/src/style.css">

Шрифт лежит рядом с css (./fonts/…), поэтому копировать файл стилей отдельно от папки fonts/ нельзя — относительные пути сломаются.

2. Поставить иконку

Два класса: namespace springpms-icon и имя icon-<имя>. Без namespace иконка не отрисуется — так сделано, чтобы не конфликтовать с другими иконочными шрифтами.

<span class="springpms-icon icon-chat"></span>

3. Размер и цвет

Иконка — это текст: наследует font-size и color родителя, отдельных модификаторов в пакете нет.

.demo-lg     { font-size: 40px; }
.demo-accent { color: #e11d48; }

4. Иконка рядом с текстом

<button>
    <span class="springpms-icon icon-done"></span>
    Подтвердить
</button>

5. Иконка в своём псевдоэлементе

Когда лишний <span> в разметке не нужен. Кодпоинт берётся из галереи; семейство указывается вручную, потому что вне класса springpms-icon оно не задано.

Написать в чат 
.demo-pseudo::before {
    font-family: 'spring-pms';
    content: "\e970";   /* icon-chat */
    margin-right: 8px;
}

В Sass-проекте так делать не надо — там есть переменные: content: springpmsfont.$icon-chat;, см. readme.
